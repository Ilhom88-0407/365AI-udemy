# 6-dars. Anaconda Assistant — Python vositalari

## 🎬 Boshlashdan oldin

> **"Salom! Anaconda assistentining imkoniyatlarini o'rganaylik."**
>
> ## **"Bu vosita shu qadar KUCHLIKI, agar biz muayyan dasturlash muammosini qiyin deb topsak — u hatto uni HAL QILISHNI BOSHLASHGA ham yordam bera oladi."**

*(12-modulning 5 va 6-darslarida Anaconda Assistant bilan tanishgan edingiz.)*

---

## 1. Muammoni hal qilish

> **"Anaconda assistentining bu xususiyatini ko'rsatish uchun yangi noutbuk yaratish maqsadida ekranning yuqori chap burchagidagi PLYUS belgisini bosaylik."**
>
> **"Keyin biz Anaconda assistentiga ANIQ va IXCHAM vazifa qo'yamiz."**

### So'rov

```
Create a function that takes a list object as a parameter
and that counts the number of values in it smaller than 20.
```

*(Ro'yxat obyektini parametr sifatida qabul qiladigan va undagi 20 dan kichik qiymatlar sonini hisoblaydigan funksiya yarating.)*

> **"Bir necha soniya kuting. Va ajoyib!"**
>
> **"Biz nafaqat YECHIMNI, balki funksiya bilan ishlatish uchun ARGUMENT qiymati bo'yicha TAKLIFNI ham olamiz."**

---

## 2. Natijani solishtirish

> **"Ikkala kod bo'lagini noutbukda ishga tushiraylik. Avval kerakli vazifani bajaruvchi funksiyani yarating, keyin uni assistent bergan qiymatlar bo'lgan ro'yxatga qo'llang."**
>
> **"Ko'rib turganingizdek, u to'g'ri ishlaydi. Ajoyib."**

> **"Endi yangi funksiyaning tuzilmasini biz ma'ruzada muhokama qilgan funksiya bilan tuzilma va funksionallik nuqtai nazaridan solishtiraylik."**
>
> ## **"Ikkala funksiya BIR XIL, to'g'rimi?"**

> **"Bu shuni anglatadiki, biz assistentning natijasidan ham, o'z ishimizdan ham juda mamnun bo'lishimiz mumkin."**
>
> **"Ikkala funksiya orasidagi YAGONA farq — ular ichida ishlatilgan o'zgaruvchi va funksiya NOMLARI."**

---

## 3. Suhbatni davom ettirish

> ## **"Esda tuting: u bilan muloqotda DOIM iloji boricha ANIQ bo'lishga harakat qiling."**

> **"Faraz qilaylik, hozirgi vazifamiz — endigina olgan kod bo'lagidagi barcha obyekt nomlarini ma'ruzada ishlatilganlariga moslashtirish."**

### So'rovlar ketma-ketligi

```
1.  Rename function to "count".
    (Funksiya nomini "count" ga o'zgartiring.)

2.  Change the input parameter name from lst to numbers.
    (Kirish parametri nomini lst dan numbers ga o'zgartiring.)

3.  Change the iterator variable name to x and the count variable name to total.
    (Iterator o'zgaruvchi nomini x ga, count o'zgaruvchisi nomini total ga o'zgartiring.)
```

> **"To'g'ridan-to'g'ri yozib bajarishimiz mumkin: `Rename function to count`. Yaxshi."**
>
> **"Yana nima qilishimiz kerak? `Change the input parameter name from lst to numbers`."**
>
> **"Enter yoki yashil tugmani bosing. Va yana biz yaxshi javob oldik."**

> ## **"Aslida men BITTA SO'ROV bilan ikkita zarur o'zgartirishni hal qila olaman."**
>
> **"Odatdagidek, men iloji boricha aniq bo'lishga harakat qilaman."**
>
> **"Men iterator o'zgaruvchi nomini `x` ga, `count` o'zgaruvchisi nomini `total` ga o'zgartirish haqida so'rayman."**
>
> **"Bajaring — va biz ma'ruzada ishlatgan kodni olamiz."**

> ## **"TO'G'RI TERMINOLOGIYADAN foydalanish bizga BITTA so'rov bilan davom etishga qanday yordam berganini payqadingizmi?"**

> 🔑 **Asosiy saboq:** *iterator*, *parametr*, *funksiya* kabi **to'g'ri atamalarni** bilsangiz — AI bilan **tezroq va aniqroq** ishlaysiz.

---

## 4. ⚠️ AI o'ziga zid bo'lishi mumkin

> **"Fikrimni tasvirlash uchun men ataylab NOANIQ va CHALKASH savol beraman."**

> **"Agar javoblarni diqqat bilan tekshirsangiz, ular BIR XIL EMASLIGINI va AI vosita SHUBHA QILA BOSHLASHI mumkinligini payqaysiz."**

> ## **"Shuning uchun biz assistent taklif qilgan narsalarni DIQQAT BILAN O'QIB, ehtimoliy XATOLARNI TOPISHIMIZ kerak."**

## 6. Muqobil yechim so'rash

> **"Bir necha qadam orqaga qaytgandan so'ng, men assistentdan dastlabki vazifaga MUQOBIL yechim topa oladimi deb so'rashim mumkin — masalan, `for` o'rniga `while` siklidan foydalanib."**

### So'rov

```
Can you create a function that has the same purpose and structure,
but uses a while instead of a for loop?
```

*(Bir xil maqsad va tuzilmaga ega, lekin `for` o'rniga `while` sikldan foydalanadigan funksiya yarata olasizmi?)*

> **"E'tibor bering: modellar biz suhbatni davom ettirgan joydagi AYNAN SHU o'zgaruvchi nomlaridan foydalangan holda funksiya hosil qildi."**
>
> **"Masalan, funksiya nomi — `count`, parametr nomi — `numbers`, va hokazo."**

> 🔑 **AI suhbat KONTEKSTINI eslab qoladi.** Shuning uchun bir necha so'rovdan keyin u sizning uslubingizga **moslashadi**.

## 9. 💡 Amaliy maslahatlar

### ✅ Yaxshi so'rov

```
Create a function that takes a list of integers and returns
the count of values greater than 100.
```

**Nima uchun yaxshi:** aniq **kirish** (`list of integers`), aniq **chiqish** (`count`), aniq **shart** (`greater than 100`).

### ❌ Yomon so'rov

```
Make something with numbers
```

**Nima uchun yomon:** hech narsa aniq emas.

### 📏 Yaxshi so'rovning 4 qismi

```
1. NIMA yaratish kerak      →  "Create a function..."
2. NIMANI qabul qiladi      →  "...that takes a list of integers..."
3. NIMA QILADI              →  "...and counts the values..."
4. QANDAY SHART bilan       →  "...smaller than 20."
```

## 10. ⚡ Amaliy mashqlar

> 📌 Bu darsda kod mashqlari yo'q — bu **AI bilan ishlash ko'nikmasi**. Quyidagilarni **o'zingiz sinab ko'ring**.

### 🟢 Oson

**M1.** Anaconda Assistant'dan ro'yxatdagi **juft sonlar sonini** hisoblaydigan funksiya so'rang.

**M2.** Uning natijasini o'zingiz yozgan variant bilan **solishtiring**.

**M3.** `Explain the selected code` bilan o'z kodingizni tushuntirtiring.

### 🟡 O'rta

**M4.** Bir so'rov bilan **ikkita** o'zgartirish so'rang (funksiya nomi + parametr nomi).

**M5.** `Add comments to the selected code` bilan izohlar qo'shtiring. Ular **to'g'rimi**?

**M6.** `for` bilan yozilgan kodni `while` ga o'girtiring.

### 🔴 Qiyin

**M7.** Ataylab **noaniq** savol bering va javoblarni solishtiring. AI o'ziga **zid bo'ladimi**?

**M8.** `Refactor the selected code` bilan kodni soddalashtiring. **Notanish vositalar** taklif qilinadimi?

**M9.** AI bergan kodda **xato** toping. *(Har doim ham topilmasligi mumkin — lekin qidirish odati muhim.)*
