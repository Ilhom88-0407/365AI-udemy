## 6. ⌨️ Jupyter — eng qulay usul

> ## **"Aslida ko'p vaziyatlarda Jupyter bizga kerakli ma'lumotni hujjatlardan ANCHA QULAYROQ tarzda olishga yordam bera oladi."**

### Tab — nomni to'ldirish

> **"Jupyter notebook fayliga o'taylik. Bu yerda biz `list_1` ni yaratganmiz va uni `list_2` da mavjud elementlar bilan kengaytirmoqchimiz."**
>
> **"Ro'yxat nomini yozib, nuqta operatorini qo'yganimizdan so'ng, **Tab** tugmasini bosishimiz mumkin."**
>
> **"Bu Jupyter'ni bu yerda ishlatishimiz mumkin bo'lgan metodlar bo'yicha bir necha TAKLIF berishga undaydi."**

```
list_1.  →  [Tab]
            ┌──────────┐
            │ append   │  ← alifbo bo'yicha birinchi
            │ clear    │
            │ copy     │
            │ count    │
            │ extend   │  ← kerakli metod
            │ index    │
            │ ...      │
            └──────────┘
```

> **"`append` alifboning birinchi harfi bilan boshlangani uchun u mantiqan ro'yxatning yuqorisida. Biz `extend` ni ham ko'ramiz. Uni tanlash uchun klaviaturadan **Enter** tugmasini bosing."**

### Tab — argumentni to'ldirish

> **"Keyin qavslarni oching va ular ichida turganingizda `list_2` nomining faqat dastlabki bir necha harfini yozing."**
>
> **"Keyin **Tab to'ldirish** dan foydalaning. Ya'ni bir necha taklif olish uchun Tab tugmasini bosishingiz mumkin — ulardan biri aynan sizga kerak bo'lgani: `list_2`. Uni tanlang va yana Enter bosing."**

### Shift + Tab — hujjat

> ## **"Kursoringiz hali ham qavslar orasida turganda, **Shift** tugmasini bosib turing va **Tab** tugmasini TO'RT MARTAGACHA bosing — `extend` metodi haqida turli xil ko'rinishlarda ma'lumot olish uchun."**

```
Shift + Tab  ×1  →  qisqa eslatma
Shift + Tab  ×2  →  to'liqroq
Shift + Tab  ×3  →  butun hujjat
Shift + Tab  ×4  →  pastki panelda ochiladi
```

> **"Tan olishim kerak: Jupyter ko'rsatadigan hujjat rasmiy Python veb-saytidan topishingiz mumkin bo'lganidek TO'LIQ EMAS."**
>
> ## **"Shunga qaramay, bu Jupyter vositasi — HAQIQIY QOTIL. U nihoyatda foydali, chunki u sizga ma'lum metodning funksionalligini tavsiflovchi ma'lumotni izlash uchun DOIM internetga kirish vaqtini TEJAYDI."**

### Funksiyalar uchun ham

> **"Yon eslatma sifatida, bu Jupyter vositasi FUNKSIYALAR uchun ham ishlashini ko'rsatay."**
>
> **"Masalan, `string` funksiyasini yozayotganda, kursorni qavslar orasiga qo'yib, **Shift** ni bosib turib **Tab** ni bossangiz — bu ichki funksiya haqida ham ma'lumot olasiz."**

## 9. 💻 Amaliy: `help()` — Jupyter siz

Jupyter'siz ham xuddi shu ma'lumotni olish mumkin:

```python
# ===== METOD =====
help(list.extend)
help(list.append)
help(str.upper)
help(dict.get)

# ===== FUNKSIYA =====
help(len)
help(str)
help(sorted)

# ===== NIMA METODLAR BOR? =====
r = [1, 2, 3]
metodlar = []
for m in dir(r):
    if not m.startswith("_"):
        metodlar.append(m)
print(metodlar)

s = "Python"
str_metodlar = []
for m in dir(s):
    if not m.startswith("_"):
        str_metodlar.append(m)
print(len(str_metodlar), "ta str metodi")
print(str_metodlar[:10])

# ===== AMALDA =====
list_1 = [1, 2, 3]
list_2 = [4, 5]
list_1.extend(list_2)
print(list_1)
```

**Natija:**

```
['append', 'clear', 'copy', 'count', 'extend', 'index', 'insert', 'pop', 'remove', 'reverse', 'sort']
47 ta str metodi
['capitalize', 'casefold', 'center', 'count', 'encode', 'endswith', 'expandtabs', 'find', 'format', 'format_map']
[1, 2, 3, 4, 5]
```

> ⚠️ Metodlar soni Python versiyasiga qarab **farq qilishi mumkin**.
